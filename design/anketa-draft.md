# Финальная анкета (уроки спринта)

> Готовый материал для заполнения формы финальной анкеты от команды.
> Структура — по промежуточной анкете (техстек, компоненты, что попробовали,
> грабли) + вынесенные уроки.

## Проект одной строкой

Memory Curator — база знаний агента, которая сама себя улучшает: сохраняет
проверенные факты из сессий, ищет дубликаты и противоречия, помечает устаревшее
и раскладывает знания по структуре документации проекта.

## Техстек

- Python, без LLM в бэкенде (извлечение знаний — на слое агента)
- MCP-сервер (stdio) — интеграция с opencode и Claude Code
- Хранилища: SQLite (локально, офлайн-fallback с outbox) + xmemory (облако)
- pytest — 299 тестов (юнит / requirements / e2e)
- Установка: `install.sh` / `curator install` — одна команда, ноль вопросов

## Основные компоненты

- **MCP-сервер** — 9 тулзов (capture, query, status, report, feedback…)
- **Gatekeeper** — human-in-the-loop: preview + подтверждение по умолчанию
- **Improve loop** — дубликаты, противоречия, устаревание + метрики до/после
- **Eval-гейт** — проверка перед каждым изменением базы
- **Observability** — JSONL-трейс «урок X → изменение Y → результат Z»
- **Реестр типов** — Reference/Style/Tool/Spec + расширение через подтверждение
- **MapRouter** — маршрутизация знаний по карте документации проекта
- **Фоновый worker** — автономный improve + телеметрия
- **Инсталлер** — автодетект харнеса, команды, скиллы, mcp-конфиг

## Что попробовали / решения

- **Pivot: LLM вне бэкенда.** Извлечение знаний делает агент (у него контекст
  сессии), бэкенд только валидирует и хранит. Результат: мгновенные ответы,
  ноль расходов на токены, детерминированность. Контракт `candidates`.
- **Время не делает знание ложным.** Таймерный decay выпилен; устаревание
  только семантическое: eval-гейт, проигравшие противоречий, дубликаты,
  решение человека. Телеметрия использования — observability, не приговор.
- **Молчаливый фолбэк запрещён.** Неизвестный тип факта — reject со словарём
  описаний, а не подмена на «похожее». Новые типы — только через
  подтверждение человека.
- **Команды = продукт.** 9 слэш-команд (/curator-*) мержатся в конфиг харнеса
  при установке — функциональность доступна как команды, не только через диалог.
- **Установка без вопросов.** Одна команда: автодетект харнеса, дефолты молча,
  результат в `curator status`. Смена поведения — через агента.
- **MapRouter.** Знания раскладываются по карте документации проекта
  (интеграция со скиллом mapping-documentation) — база ложится в структуру
  команды, а не в один файл-мешок.
- **Dogfooding.** Прогон на живых данных нашёл баг в собственной легаси-схеме
  БД — починили в тот же день.

## Грабли (что сломалось и чему научились)

- **Агент-извлекатель норовит сохранить мусор.** Фичевые детали, гипотезы,
  проект-специфика — всё идёт в кандидаты. Решение: gatekeeper + preview с
  подтверждением (human-in-the-loop по умолчанию); молчаливые фолбэки
  запрещены — неизвестный тип = reject со словарём, не подмена.
- **LLM в бэкенде = таймауты, расходы и недетерминированность.** Первый дизайн
  звал модель на каждый запрос. Pivot: извлечение делает агент, бэкенд только
  валидирует и хранит — мгновенно и дешёво.
- **Дубликаты и противоречия копятся сами собой.** Повторное сохранение одной
  мудрости — норма жизни. Natural key (title) + UPSERT, improve loop объединяет
  дубли, противоречия разрешаются по правилам (verified бьёт hypothesis),
  eval-гейт перед каждым изменением.
- **Устаревание по таймеру ложно.** Непопулярный факт ≠ ложный: таймерный
  decay выпилен, телеметрия — observability, не приговор. Устаревание только
  семантическое.
- **Авто-удаление знаний опасно.** Факт помечается [УСТАРЕЛО] в .md вместо
  удаления — история и provenance сохраняются, rebuild не воскрешает помеченное.
- **База без структуры превращается в мешок.** MapRouter + реестр типов +
  карта документации проекта — знания ложатся в структуру команды, а не в
  один файл.
- **Облачная память падает вместе с сетью.** Offline-first: локальная SQLite +
  outbox, `curator sync` пушит при появлении сети — агент не замечает
  пропажи облака.
- **Интеграция с харнесами: конфиги правят руками.** Повторная установка
  обязана быть патчем — сохранять базу и чужие секции, парсер терпит
  jsonc-хвосты.
