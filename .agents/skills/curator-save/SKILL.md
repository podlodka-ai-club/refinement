# Curator Save

Сохранение знаний из сессии в базу через MCP-сервер memory-curator.

## Когда срабатывать

- Явная просьба: «сохрани знания», «запомни это», `/curator-save`
- **Проактивно**: в ходе сессии выяснили что-то проверённое (подтверждено
  исходниками, логами или устройством) и абстрактное (не привязано к
  конкретной задаче) — предложи: «Выяснили проверенное знание — сохранить
  в базу?». Не сохраняй без подтверждения пользователя.

## Что сохранять, а что нет

- Да: проверенные правила, паттерны, принципы — подтверждённые и абстрактные
- Да: принципы, решения, стиль и мудрость, высказанные пользователем в сессии —
  кандидаты не только технические факты
- Нет: фичевые детали, конкретные баги, неподтверждённые гипотезы,
  проект-специфичные детали

## Шаги

1. Извлеки из сессии кандидатов — не только технические факты: принципы,
   решения, стиль и мудрость пользователя — равноправные кандидаты.
   Для каждого — `type`, `title` (одна строка,
   ≥10 знаков), `content_summary` (1-2 предложения), `tags`, `evidence`
   (цитата из сессии). Контракты формата: заголовок — одна строка без `#`;
   описание — без строк, начинающихся с `#` или `*Тип:*`/`*Теги:*`; теги —
   без `|` и `,`. Gatekeeper отклонит нарушителей — не пытайся обойти.
2. **Выбор типа — по описаниям, не по догадке.** Список типов с их
   семантикой: вызови `curator_status` (раздел «Типы»). Факт ложится в
   описание типа → это его тип. Не ложится ни в один → предложи человеку:
   «завести новый тип? Предлагаю `Note` — заметки об инструментах».
   Человек выбрал новый → передай `new_type: true` + `type_description`
   (что значит тип — минимум 10 знаков; ядро зарегистрирует).
   Неизвестный тип без new_type ядро отклонит — это защита от молчаливой лжи.
3. Self-review: вызови `curator_query` с релевантыми ключевыми словами;
   убери кандидатов, которые уже есть в базе.
4. Покажи пользователю preview и спроси подтверждение (все / выборочно / отказ).
5. После подтверждения вызови `curator_session_capture` с `auto_approve=true`
   и выбранными кандидатами.
